How this wiki works

One file per dataset

Facts live in datasets/<slug>/dataset.yaml, prose in an optional page.md. Numbers in prose are shortcodes into the record, so there is one place to fix a fact.

Validated before merge

A strict schema rejects unknown fields and bad enums; cross-references (families, organizations, successors) are checked in CI. Invalid records cannot be merged.

Evidence, not vibes

Each availability status carries a verification date, who verified it, the URL that was checked and, where possible, a Wayback snapshot. Status changes are recorded as dated history.

Tooling

All recorded datasets are readable through py123d, which converts them into one Arrow format with a single API. Records link the matching conversion configs.

Embodied Datasets

A community-maintained wiki of autonomous driving datasets, with availability as a first-class, dated, evidence-backed field.

Records are CC BY 4.0, code is MIT. Facts are only as good as their sources: every record links its evidence and names who verified it last.
